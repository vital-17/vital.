# 基于大模型的RAG智能问答系统
## 项目简介
本项目结合检索增强生成技术，搭建私有知识库问答应用。依托文本向量化、语义检索与大模型生成能力，解决通用大模型知识滞后、幻觉问题，精准基于本地文档内容给出回答，可适配文档咨询、企业知识库、智能客服等场景。

## 技术栈
- 编程语言：Python
- 核心框架：LangChain
- 深度学习：PyTorch、Transformer架构
- 向量检索：FAISS
- 向量化算法：余弦相似度、词嵌入Embedding
- 部署相关：本地调试、基础容器运行

## 核心功能
1. 文档解析：支持PDF、TXT格式文件读取与内容提取
2. 文本切分：长文本分片处理，适配检索与模型输入长度限制
3. 语义向量化：将文本转为高维向量存储
4. 相似度召回：通过余弦相似度匹配相关性最高文档片段
5. 提示词工程：优化输入话术，约束模型输出逻辑
6. 智能问答：结合检索内容生成贴合资料的答案

## 项目架构
文档加载 → 文本分割 → Embedding向量化 → 向量库存储 → 问题向量化 → 相似度检索召回 → 上下文拼接 → LLM推理生成回答

## 关键原理
1. 自注意力机制依托向量点积、余弦相似度计算文本语义关联
2. RAG检索环节依靠向量匹配筛选有效参考信息
3. 引入参考资料降低模型凭空生成概率，提升回答真实性
